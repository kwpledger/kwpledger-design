The Microsoft Office side of the system, copied from the repository's `office/`. `theme-colors/kwp-design.xml` maps the tokens onto Office's twelve theme-color slots: Dark 1 is `fg` (ink-900), Light 1 is `surface-card` (paper-0), Accent 1 is `accent` (teal-700), and Accents 2–6 are `data-1-fg` … `data-5-fg` in slot order. `theme-fonts/kwp-design.xml` sets Lora for headings and Hanken Grotesk for body. `swiss-deck/*.potx.zip` each hold one PowerPoint template, built from them, unchanged; unzip for the `.potx`. Start a deck from a template rather than from a blank file, and keep Accent 1 for the brand, not for a category. tokens/ wins if a value here ever disagrees.
