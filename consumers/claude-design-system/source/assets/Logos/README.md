The kwp signature marks, vendored byte-for-byte from the repository. Naming runs broad to narrow: `logo_{long|short}[_ring][_inv][_<color>].svg`. Black-ink files are for light grounds; `_inv` files (white glyph, black outline) are for dark grounds. Every file is single-ink except the ring, which carries its aspect color in the file itself; no file inherits color. Defaults: `logo_short_ring_teal.svg` on light, `logo_short_ring_inv_teal.svg` on dark. `_ring` and `_ring_inv` with no color suffix are the `#0026FF` placeholder: never ship them. The `kwp_logo_*` files are the superseded raster set, kept for reference. Size by height, width auto. PROVENANCE.md is the authority on these files.
