# TypeScale

The two text faces and the six fluid steps, live. Use it to pick a step and a face.

- Set sizes with `var(--step-N)` from `components/bundle.css`; set headings in `var(--font-display)` at `var(--fw-display)`.
- Cap body copy at `var(--measure)`.
- `--font-mono` and `--font-hand` are covered in the brand book; neither appears here.
