# SystemRules

The constraints every surface inherits, each with its failure mode: the three layers, the 0.091 chroma ceiling, color as reinforcement, light and dark authored together, one register per fixed canvas, and the naming rules. Read it before generating anything.

- Components consume the semantic layer only; domain tokens live in the consuming app.
- Categorical slots are numbered; status tokens are named for meaning.
- Write `kwp` in lowercase.
