# Infographic

The 1080×1350 (4:5) infographic format: a stacked or two-column layout in the light register, categorical slots in order, a neutral card with the tint on the chip, 120–180 words, and the black `logo_long.svg` in the footer.

- The consumer supplies the copy and a row per idea; every row carries a text label.
- Start from a rendered example in `assets/Examples/` and the infographic section, not from a blank canvas.
- Do not skip or reorder `data-N` slots to get a hue.
