A loader where only the ring moves

Level 9

At game size, bottom right, while the next screen loads.

Enlarged. The initials stay put the whole time, shown from the original file as a still image. Only the ring moves. It draws clockwise from the upper left, where the k's tall stroke sits, all the way round. After a short beat it erases clockwise from the same point, so the tail chases the head, then it starts again. One cycle takes 2.6 seconds. The ring sits under the initials, as it does in the ringed file, so at full draw you see exactly the mark. With reduced motion on, it shows the complete mark and stays still.
