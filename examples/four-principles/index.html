When being wrong is expensive

Four questions that turn
“use AI responsibly” into a workflow

An artifact that fails any one of the four is not ready to use.
Principle 1

Human-Owned

A named person owns the decision and the outcome.

AI drafts; it cannot be accountable.

AskWho is accountable if this is wrong?
Principle 2

Source-Grounded

The human picks the sources and checks the version.

Grounding cuts fabrication, not risk.

AskWhat is this based on?
Principle 3

Verifiable

A qualified reviewer can check it against evidence.

Sounding reasonable is not checking.

AskCan we prove this is correct?
Principle 4

Traceable

A reviewer can retrace source, check, and approval.

A finished file is not a record.

AskCan we reconstruct where this came from?
