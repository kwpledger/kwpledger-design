LinkedIn banner — 1584×396

A layer-3 consumer format at 4:1. LinkedIn's native profile-header size, so it uploads with no resampling at all — unlike the quote card's 7:5, which is native nowhere.

The left 528px carries no content. Ever. The profile photo covers the lower left, and the mobile crop trims that edge first. 528 is one exact third, and it is deliberately more conservative than LinkedIn's current chrome requires — a survivability margin, not a measurement. Nobody gets a notification when a header starts clipping.

Two modes

The spec in short

Canvas1584×396 (4:1). Exports JPG q92.
RegisterDark (§3), pinned. Chosen, not inherited — a light-bordered profile photo separates from a dark header without a stroke.
Budget300px of content height. Mode A measures 273, Mode B 196.
AccentThe eyebrow, once. The meta rule is --border, so teal never appears twice.
Marklogo_long_inv.svg, 96px tall, width auto. No ring — that is the quote card's badge, and repeating it would make two formats look like one artifact.
CopyTitle ≤ 9 words, subtitle ≤ 12. Read while scrolling, at maybe half this size.
Mode B is the resting state, not a fallback. A banner still advertising a conference that already happened is worse than one advertising nothing, so switching back is part of finishing an event rather than a separate task.
